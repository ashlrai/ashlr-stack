# Changelog

## 0.6.0 (2026-08-01)

### Added

- Double fence: ``stack add `x`y`` keeps the inner backtick.
- Triple fence: ```a``b``` holds a double backtick.
- A span that wraps
  across a line: `stack apply
  --dry-run` stays one span.
- An escaped \`tick\` outside a span is plain text.
- Span in a nested item:
  - Inner `--json` flag.
